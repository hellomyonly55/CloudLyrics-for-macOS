# 稳定性修复验证（2026-11-10）

## 行为变更

- 菜单栏按可见文本中较宽的一行计算长度，最小 134 pt，保留三个播放控件所需空间。设置中的宽度为上限，新安装默认 240 pt，已有设置保留。
- 控件直接处理鼠标事件，三个命中区域互不重叠。按下和抬起之间目标变化时取消点击，避免歌词宽度变化后执行其他按钮。右键打开设置。
- 上一首/下一首只调用目标播放器的菜单命令，禁止 MediaRemote 导航回退；菜单不可用或缺少辅助功能权限时显示错误。整合 #4 的路由策略。
- 播放器识别查询当前进程，不依赖启动/退出通知。
- 歌词请求失败后在 5、15、45、60 秒后重试，之后每 60 秒重试；切换曲目或手动刷新会重置退避。

## 验证

自动测试覆盖紧凑布局、歌词可用宽度、真实鼠标事件路由、拖动取消、缺失进程通知、导航路由及歌词请求失败后的恢复。

本机原安装为 CloudLyrics 0.2.2；网易云版本为 3.1.12。启动网易云后，进程被正确识别，辅助功能能够找到「上一个」「播放」「下一个」菜单。播放数据读取被 macOS 拒绝，诊断明确显示完整磁盘访问权限提示，而不是「未运行」。因此没有宣称完成真实歌曲同步或实际切歌的端到端验证；也不将这一结果视为 3.1.12 本地数据格式已兼容。

系统权限必须通过系统设置授予对应的 CloudLyrics 应用；辅助功能权限和完全磁盘访问权限是两项不同授权。未修改系统权限或播放器数据。
